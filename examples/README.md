# RendererCheck examples

- `basic-c`: dependency-free deterministic committed-baseline regression fixture and custom metrics.
- `glfw-opengl`: raw OpenGL framebuffer capture through GLFW.
- `raylib`: real raylib framebuffer capture with warm-up frames.
- `sdl3`: real SDL3 renderer capture.
- `vulkan-validation`: real `VK_LAYER_KHRONOS_validation` pass/fail integration.
- `metal`: macOS offscreen Metal render-target capture.

Every example uses the public RendererCheck integration headers and the `renderercheck` CLI.
