# RendererCheck

Graphics CI for native renderers.

RendererCheck tests native graphics projects for visual regressions, validation errors, renderer performance regressions, and headless/CI execution.

**Documentation:** https://xt9y.de/rendercheck.html

## Install

```bash
git clone https://github.com/xt9y/RendererCheck.git
cd RendererCheck
make
sudo make install
```
